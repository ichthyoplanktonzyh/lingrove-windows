# Canonical category sidebar and manager

Reference: frozen macOS `35b7fbe5c788c5524936ade1dfb7c89a3a285b04`, `Lingrove/UI/Vocabulary/VocabularyCategorySidebar.swift`, `VocabularyCategoryEditor.swift` (`VocabularyCategoryManager`) and `VocabularyMeaningCategorySheet.swift`, with `LingroveTests/UI/Vocabulary/VocabularyClassificationViewTests.swift` and `LingroveTests/Services/Vocabulary/VocabularyClassificationPersistenceTests.swift`. The Store contract and detached category/membership editor are documented in `VOCABULARY_CANONICAL_SEMANTICS_STORE.md` and `VOCABULARY_CANONICAL_CATEGORY_SHEETS.md`.

In meaning organization, the existing category sidebar now exposes New, Manage and row Edit when the borrowed Store implements the canonical semantic capability. New inherits the selected category as a parent and selects the acknowledged new category, subject to hidden/retired reconciliation. The manager searches nonretired categories including hidden ones, edits either kind through the same category sheet, toggles visibility through classification overrides, and asks for confirmation before deleting a custom category. Bundled categories cannot be deleted and their protected definitions/parents remain unchanged. Removing a category removes its edges and memberships while keeping meanings and expressions. Hiding or deleting the active filter reconciles selection to All meanings.

The manager borrows the same Store, subscribes before reading the current snapshot to cover commits between the caller's snapshot and subscription, and accepts only nonstale revisions. Detached notifications use a one-pending-dispatch maximum-revision coalescer. Retirement cancels and joins the initial read even if its implementation ignores cancellation, and prevents late results from publishing. It also joins child edit/confirmation modals and accepted writes before unsubscribing; failures leave the manager open, display the error and restore the acknowledged checkbox state. The notebook likewise restores enabled state after modal dismissal and hide/reopen. Existing noncanonical sidebar callers retain their original default behavior and do not receive the scoped menu style.

WPF uses the notebook theme with Segoe UI Variable/Segoe UI, 96-DPI units, native selection and scrolling, and high-contrast system brushes. Tests drive real isolated SQLite and WPF controls for sidebar child creation/edit, inherited axis/parent, built-in hide/restore and overlay protection, custom edit/delete/cancel, membership and meaning retention, selected-filter reconciliation, external revision updates, failure recovery, and accepted-write retirement. Optional light/dark/simulated-high-contrast renders do not establish real high contrast, screen-reader, per-monitor DPI, physical mouse/keyboard or desktop acceptance. Usage-pattern and other unsupported notebook actions remain visibly disabled.
