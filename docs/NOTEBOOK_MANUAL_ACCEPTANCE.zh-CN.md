# 生词本：意义与分类人工验收

用于主智能体交付并标记“待人工验收”的 Windows 候选。这里只检查本轮已接通的意义、分类流程；
构建成功、控件测试通过和离屏截图均不代替下面的结果。本轮采用新的版本化生词本，旧文件保留，
其中的数据不会自动导入。此流程不需要模型或 Anki。

1. 从托盘打开 **Vocabulary**。点击 **Add entry**，创建英语 `bank`，Core meaning 填 `financial institution`。
   保存后应选中新条目；再打开 **Edit**，修改释义并保存，关闭重开仍保留。
2. 在义项详情选择 **New meaning**，创建 `Finance`。保存后应进入对应意义分组，能看到 `bank`；
   编辑分组名称，再取消一次编辑，确认取消没有写入。
3. 在意义详情打开 **Categorize**，创建一个自定义分类并勾选保存。
   在分类侧边栏选择它，应能找到该意义分组；取消另一次归类不应改变已保存关系。
4. 从侧边栏新建子分类，检查其继承当前分类作为父级，保存后选择新分类。
   打开分类编辑，确认名称、描述和父级保存重开后仍正确。
5. 打开 **Manage categories**，搜索、隐藏再显示一个内置分类。
   内置分类不应提供真实删除。隐藏当前所选分类后应回到全部视图。
6. 删除刚创建的自定义分类：先取消确认，确认分类仍在；再确认删除。
   `Finance` 意义分组与 `bank` 词条应继续保留。关闭重开生词本，确认状态保持。
7. 检查浅色／深色下文字、选中态和按钮是否清楚；缩窄窗口、滚动长列表、使用 Tab 和 Enter。
   有条件时再检查 150%／200% 缩放和系统高对比度，记录遮挡、裁切或难以辨认的状态。

反馈格式：候选版本、失败步骤编号、实际表现、Windows 缩放；视觉问题附对应窗口截图。
Word、Chrome、Codex 中的补全／翻译／输入法验收另按宿主清单执行，不向 Codex 提交测试消息。
